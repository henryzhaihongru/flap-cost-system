# 砂布成本及报价计算系统

面向砂布产品的成本计算、基础数据维护与报价记录管理。根据尺寸、页数、砂布单价及材料、人工、管理和运费，比较三档加价率下的报价；管理员可保存其中两档结果。

当前版本使用 **Node.js / Express / SQLite**，前端为原生 HTML、CSS 和 JavaScript。它可以展示业务建模、接口设计、权限控制及缺陷修复经历；Java / Spring Boot 后端尚未实现。

## 功能

- 规格选择自动填充尺寸与成本，磨料 → 编号 → 粒度联动查询价格。
- 成本拆分、三档报价对比，管理员保存、查看和删除报价记录。
- 管理员维护产品规格、砂布价格；游客可计算，不能维护数据或读取报价记录。
- scrypt 密码哈希、随机会话令牌、数据库仅保存令牌摘要，HttpOnly / SameSite Cookie。
- 连续登录失败限制、修改密码后注销该账号的所有会话。
- 启动自动建表并补齐旧库的第二档报价字段。

## 本地运行

需要 Node.js 22 或更新版本以及 npm。在项目根目录打开 PowerShell：

```powershell
cd backend
npm ci
$env:ADMIN_USERNAME="admin"
$env:ADMIN_PASSWORD="请替换为你自己的至少8位密码"
$env:VISITOR_USERNAME="visitor"
$env:VISITOR_PASSWORD="请替换为另一个至少8位密码"
npm run seed:demo
npm start
```

访问 `http://127.0.0.1:3000`，使用刚设置的账号登录。演示价格与成本全部为虚构数据，初始化演示数据不会清空已有数据。不运行 `seed:demo` 也能启动，管理员可自行录入基础数据。

账号环境变量只在对应角色账号不存在时创建账号；以后修改环境变量不会重置已有密码。已有账号可通过网页修改密码，或在 `backend` 中执行 `npm run reset-password -- admin "新的至少8位密码"`。

默认数据库为 `database/database.sqlite`。可通过 `DATABASE_PATH` 指定隔离数据库，`PORT` 修改端口，`HOST` 修改监听地址。默认仅监听本机；需要对外部署时显式设置 `HOST`，并使用 HTTPS。生产环境设置 `NODE_ENV=production` 后，会话 Cookie 仅通过 HTTPS 发送。

## 业务规则与限制

报价使用成本加价率，并非销售毛利率。税相关系数 1.13 和报价换算系数 1.08 沿用原系统业务算法，作为演示规则展示，不代表税务建议。

计算仍在浏览器进行，服务端校验字段格式后保存结果，尚未独立复算价格；当前金额使用 JavaScript Number 和 SQLite REAL。后续可将计算迁入服务层，以十进制定点金额和报价快照增强一致性。第三档报价目前仅展示，未保存。

登录失败计数保存在单进程内存中，重启后重置；当前版本不包含完整生产环境限流、集中式日志或备份恢复方案。原来错误保存为 0 / 1 的历史金额无法由字段迁移自动还原。

接口与计算口径见 [业务与接口说明](docs/API.md)。修复和验证记录见 [发布说明](docs/RELEASE.md)。

## 数据边界

仓库不包含真实数据库、账号、登录会话、客户报价或供应商价格。不要将本仓库生成的演示数据库覆盖线上数据库。
